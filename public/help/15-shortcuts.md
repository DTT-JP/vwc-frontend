# キーとボタンの一覧

| キー | はたらき |
|---|---|
| `Ctrl/Cmd + S` | 保存 |
| `Ctrl/Cmd + F` | ページ内検索の表示／非表示（右側に出ているページなら、どれでも使えます） |
| `Ctrl/Cmd + P` | ファイル名で検索 |
| `Tab` | エディターで字下げ（スペースを入力）。コード補完がONで補完候補が表示されているときは、候補の確定 |
| `Enter` / `Shift+Enter` | （検索欄で）次へ／前へ |
| `↓` `↑` | （検索欄で）次へ／前へ。補完候補の選択にも使われます |
| `→` `←` | （検索欄で、文字の端にいるとき）次へ／前へ |
| `Esc` | 検索バーやポップアップ、補完候補を閉じる。ファイル一覧では、複数選択を解除する |
| `Ctrl/Cmd + A` | （ファイル一覧を表示していて、文字入力中でないとき）ファイル・フォルダをすべて選択 |
| `Ctrl/Cmd + クリック` | （ファイル一覧で）1つずつ追加／解除 |
| `Shift + クリック` | （ファイル一覧で）範囲を選択。`Ctrl`も押すと、範囲を追加 |
| `Delete` | （ファイル一覧で）選択したものを削除（確認あり） |

> [!NOTE]
> エディターは CodeMirror 6 ベースです。コード補完の ON/OFF、折り返し、行番号、タブ幅は設定の「エディター」で変更できます。

## タブ欄のボタン
| ボタン | はたらき |
|:-:|---|
| {icon:find_in_page} | ページ内検索を表示／非表示 |
| {icon:save} | 開いているタブを保存 |
| {icon:dock_to_right} | サブ画面を開く／閉じる（スマホでは {icon:dock_to_bottom} ） |

## 検索バーのボタン
| ボタン | はたらき |
|:-:|---|
| {icon:keyboard_double_arrow_right} | 検索バーを小さくして、右上へよける（PC・タブレット） |
| {icon:search} | （小さくしているとき）検索バーを元に戻す |
