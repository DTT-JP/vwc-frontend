# エラーコード一覧

エディターの画面に表示されることがあるエラーコード（`E-A…` `E-P…`）の一覧です。表示されたコードを管理者に伝えると、原因を特定しやすくなります。

> [!NOTE]
> このページは、VWCエディター（フロントエンド）の画面に表示されることがあるコードをまとめたものです。認証システムやサーバーの内部だけで処理され、エディターの通常画面に出ないコードは掲載していません。

## ログイン・再認証（E-A）

ログインや再認証の結果として、画面の通知や戻り先の情報に含まれることがあります。

| コード | 意味 | 主な原因 | 対処 |
|---|---|---|---|
| `E-A01` | ログインが中止されました | 認証画面で操作を中止した | もう一度ログインしてください。 |
| `E-A02` | ログインの手続きが無効になりました | 10分以上経過した、別のタブで操作した、など | 最初からやり直してください。 |
| `E-A06` | 不正なログインの開始です | 開始手順が不正、または情報が不足している | トップ画面からやり直してください。 |
| `E-A11` | このアカウントは無効になっています | アカウントが無効化されている | 管理者に有効化を依頼してください。 |
| `E-A13` | 再認証は、いまログイン中のアカウントで行ってください | 別のアカウントで再認証しようとした | いまログイン中のアカウントで再認証してください。 |
| `E-A15` | ログインが切れています | 再認証の前提となるログイン状態がない | いったんログインし直してから、再認証してください。 |
| `E-A20` | 認証システムとエディターの版が合いません | 認証システムとの契約/版の不一致 | 管理者に連絡してください。 |
| `E-A21` | 認証システムに接続できません | 認証システムへの接続や応答の取得に失敗した | 少し待ってやり直してください。続く場合は管理者へ連絡してください。 |
| `E-A22` | 認証システムからの情報を確認できませんでした | 認証結果の確認に失敗した | もう一度ログインしてください。直らなければ管理者へ連絡してください。 |
| `E-A23` | この部員は、別のアカウントに結び付いています | アカウントの結び付きが一致しない | 管理者に連絡してください。 |
| `E-A24` | このアカウントは無効になっています | 認証システム側で無効と判定された | 管理者に連絡してください。 |
| `E-A99` | ログインに失敗しました | 上記に当てはまらない失敗、または不明なエラー | もう一度試し、直らなければ管理者にこのコードを伝えてください。 |

> [!TIP]
> `E-A20`〜`E-A24` は、認証システム連携に関係する失敗がエディター画面に伝わったときに表示されます。VWCエディターの操作だけでは解消しない場合は、管理者にコードを伝えてください。

## 操作・API（E-P）

保存、公開、管理操作などで表示されることがあります。

| コード | 意味 | 主な原因 | 対処 |
|---|---|---|---|
| `E-P01` | ログインの有効期限が切れました | セッションが切れた | もう一度ログインしてください。 |
| `E-P02` | この操作をする権限がありません | 権限不足（閲覧のみ、共有先の制限など） | 権限のある部員に依頼してください。 |
| `E-P03` | 管理の再認証が切れています | 管理の更新操作に必要な再認証（10分）が切れた | 「いま再認証する」を押して、もう一度操作してください。 |
| `E-P04` | 信頼端末ではありません | 他の端末のログイン承認に、信頼端末が必要 | 「端末の登録」で信頼端末にしてください。 |
| `E-P05` | 対象が見つかりません | ファイル/プロジェクト/アプリなどが削除・移動された | 画面を更新して、もう一度確認してください。 |
| `E-P06` | 他の人が先に変更しました | 保存や更新の競合 | 画面を更新して、やり直してください。必要なら差分を確認してください。 |
| `E-P07` | 別の操作が実行中です | ロック中 | 少し待ってから、もう一度操作してください。 |
| `E-P08` | ファイルが大きすぎます | アップロード/処理のサイズ上限超過 | サイズを小さくしてください。 |
| `E-P09` | 容量が上限に達しています | 利用容量（クォータ）超過 | 大きいファイルや不要なアプリを整理してください。 |
| `E-P10` | 上限に達しています | 件数などの制限超過（プロジェクト数など） | 不要なものを整理するか、管理者に上限の変更を依頼してください。 |
| `E-P11` | 公開したアプリが残っています | プロジェクト削除時に、紐づくアプリがある | アプリも削除するか、先に整理してください。 |
| `E-P12` | 操作の回数が多すぎます | 試行回数制限・ロック | しばらく待ってから、もう一度操作してください。 |
| `E-P13` | コードが違うか、期限切れです | 承認コード/アクセスコードの不一致・期限切れ | 相手の画面に出ているコードを確認してください。 |
| `E-P14` | ファイル名・フォルダ名に使えない文字が含まれています | パスの形式が不正 | 名前を変えてください。 |
| `E-P15` | 名前に使えない文字、または長さの問題があります | 名前の形式/長さが不正 | 半角英数字と `.` `_` `@` `-` などで入力してください。 |
| `E-P16` | 入力内容に誤りがあります | 必須項目不足、形式不正、許可されない操作 | 入力欄をもう一度確認してください。 |
| `E-P17` | 安全確認に失敗しました | CSRF確認の失敗 | ページを再読み込みして、もう一度操作してください（自動で1回だけ再試行する場合があります）。 |
| `E-P18` | 別のサイトからの操作は受け付けられません | Origin/Sec-Fetch-Site の確認に失敗 | このエディターの画面から操作してください。 |
| `E-P19` | 通信できませんでした | ネットワーク断、サーバー到達不可 | ネットワークを確認して、もう一度操作してください。 |
| `E-P20` | サーバーでエラーが起きました | サーバー内部エラー | 少し待って再実行し、直らなければ管理者にこのコードを伝えてください。 |
| `E-P21` | この操作は管理者だけができます | 管理者権限が必要 | 管理者に依頼してください。 |
| `E-P22` | ユーザーの追加・削除・管理者設定は、VWCから変更できません | 認証システム側の登録情報が元になっている場合がある | VWCからは変更できません。管理者に確認してください。 |
| `E-P99` | 想定外のエラーです | 未定義のエラー。`E-P99:...` のように詳細が付く場合があります | 管理者に表示されたコード（`E-P99:...` を含む）を伝えてください。 |

## 起動・画面のエラー表示（コードなし）

起動時や画面状態によっては、コード番号ではなく次のような画面/表示になることがあります。

| 表示 | 内容 | 対処 |
|---|---|---|
| 通信エラー / オフライン | サーバーと通信できない、またはネットワーク未接続 | 接続を確認し、再読み込みしてください。 |
| 起動エラー | 起動に必要な情報を読み込めない | 接続を確認し、再読み込みしてください。直らなければ管理者へ。 |
| 版の不一致 | エディターとサーバーの版が合わない | 再読み込みしてください。直らなければ管理者へ。 |
| メンテナンス中 | 保存や公開などが制限される | お知らせを確認し、終了後に再読み込みしてください。 |
| 見つかりません / 権限がありません / セッション切れ など | 対象なし、権限不足、ログイン切れ | 画面の案内に従って、再読み込み・ログイン・管理者への確認を行ってください。 |

困ったときの具体的な対処は、[困ったとき](10-trouble.md) も参照してください。
