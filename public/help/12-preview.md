# プレビュー

HTMLとMarkdown（`.md`）のファイルは、プレビューで表示を確認できます。

| 開き方 | 場所 |
|---|---|
| {icon:preview} プレビュー | ステータスバー（PC・タブレット）、または下のバーのプレビュー（スマホ） |

HTML・Markdown以外のファイルを開いているときは、プレビューは押せません（スマホでは灰色になります）。

## HTML
そのHTMLが参照している CSS・JavaScript・画像も、HTMLファイルを基準にした相対パスで読み込んで表示します。

## Markdown
ヘルプと同じ書き方（標準Markdown + VWC独自の拡張）で表示されます。表、コードの色付け、Mermaid図、画像・動画・音声の埋め込み、文字色・背景色・アイコンなどに対応します。詳しい書き方は[特殊Markdownの書き方](99-writing.md)を参照してください。

- チェックボックス（`- [ ]`）を押すと、元の `.md` ファイルが書き換わります（未保存になるので、保存してください）
- ページ内検索（Ctrl/Cmd+F）も使えます
