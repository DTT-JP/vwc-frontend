# タッチ操作・キーボードなし

キーボードがない端末でも、同じことができるようにしてあります。

| キーボードでの操作 | 画面での操作 |
|---|---|
| Ctrl/Cmd+S（保存） | タブ欄の {icon:save} 、未保存タブの {icon:circle} 、ステータスバーの保存状態 |
| Ctrl/Cmd+F（ページ内検索） | タブ欄の {icon:find_in_page} 、検索パネルのボタン |
| Ctrl/Cmd+P（ファイル名検索） | 検索パネルのボタン |
| Tab・記号の入力 | **補助キー行**（指で操作しているとき、エディター入力中に表示） |
| ドラッグ＆ドロップ | **長押し**してから動かす |
| ファイルの複数選択（Ctrl/Shift+クリック） | ファイルの行を**長押し**して離す → 以降はタップで追加／解除。下に出る操作ボタン（全選択・コピー・削除）を使う |
| ファイルの全選択（Ctrl+A） | 複数選択中に出る {icon:select_all} 全選択 |
| 左領域の幅を変える | 境目のバーをドラッグ |
| 左エリアを隠す | 選ばれている左バーのボタンをもう一度押す（PC・タブレット） |
| メインとサブの大きさを変える | 2つの画面の境目をドラッグ |

## スマホの下のバー
`戻る 進む ｜ ホーム メニュー ｜ エディター プレビュー`

| ボタン | はたらき |
|---|---|
| {icon:arrow_back} 戻る / {icon:arrow_forward} 進む | 見ていた画面を行き来する |
| {icon:home} ホーム | 押している間だけ青くなります。ホームを開く／閉じる |
| {icon:menu} メニュー | 左のメニューを開く |
| {icon:code} エディター | 編集画面へ。未保存があると赤丸が付きます |
| {icon:preview} プレビュー | HTML・Markdownを開いているときだけ押せます |

ログアウトしている間は、ホーム以外のボタンは灰色になって押せません。

> [!TIP] 補助キー行は自動で切り替わります
> 画面の幅ではなく、**指で触れているかどうか**で表示を切り替えます。マウスを使っているときは出ません。
