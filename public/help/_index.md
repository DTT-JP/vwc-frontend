# ヘルプの目次

このファイルに並べた `.md` ファイルが、ヘルプの項目になります（上から順に表示されます）。

- 項目を**増やす**：新しい `.md` ファイルを作り、下に1行追加します
- 項目を**減らす**：その行を消します（ファイルが残っていても表示されません）
- 見出しグループは `## グループ名` の行で作れます
- 並べ替えは、行の順番を入れ替えるだけです

書き方は「特殊Markdownの書き方」を見てください。
