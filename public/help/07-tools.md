# ツール

{icon:apps} ツールで、画像や音声をその場で変換します。**すべてこの端末のブラウザの中で処理**し、ファイルはサーバーへ送られません。

| ツール | できること |
|---|---|
| {icon:photo_size_select_large} 画像リサイズ | 幅・高さ（縦横比固定）、形式（jpeg / png / webp / bmp / ico）、品質 |
| {icon:content_cut} 音声カット | 波形を見ながら範囲を切り出し、好きな形式で書き出し |
| {icon:movie} 動画から音声を取り出す | 動画の音声を取り出して、好きな形式で書き出し |

## 使い方
1. **入力元を選ぶ**：「この端末から選ぶ」（ドロップも可）、または「システム（プロジェクト）のファイルから選ぶ」
2. 設定を変える（出力サイズが表示されます）
3. 出力する
   - {icon:cloud_upload} **保存**：システム（開いているプロジェクト）にアップロードします。進捗とキャンセルが出ます
   - {icon:download} **ダウンロード**：この端末に保存します

変換の進み具合は、ツールの画面と、画面右下の枠、下のステータスバーの「現在の処理」に出ます。途中で**中止**できます。変換は1件ずつ順番に行い、待っている件数も表示します。

## 読める形式と書き出せる形式
音声・動画の変換には、ffmpeg（変換エンジン）を使います。初めて使うときだけ、エンジンの読み込みに少し時間がかかります（約31MB。次からは読み込み済みです）。

| 種類 | 形式 |
|---|---|
| 読み込める音声 | wav・mp3・m4a・aac・ogg・opus・flac・wma・aiff・ac3・mp2・amr・au・caf・mka |
| 読み込める動画 | mp4・webm・mkv・mov・avi・wmv・flv・3gp・ogv・mpg |
| 書き出せる音声 | wav・mp3・flac・m4a・ogg・opus・aac |

> [!NOTE] 一覧は「実際に変換できた形式」です
> 画面の選択肢には、実際に変換して確認できた形式だけが出ます。上の一覧にない形式でも、ffmpeg が読めれば入力できる場合があります。読めないときは「形式非対応」と表示します。

## 音質（品質プリセット）
初期値は **mp3／標準／ステレオ**です。出力形式の横にあるボタンで、ステレオ／モノラルを選びます。プリセットは容量削減・標準・高音質・原音忠実・カスタムの5種類です。

| プリセット | サンプリングレート | ビット深度 | flac 圧縮レベル |
|---|---:|---:|---:|
| 容量削減 | 22.05kHz | 16bit | 8 |
| 標準 | 44.1kHz | 16bit | 5 |
| 高音質 | 48kHz | 24bit | 8 |

非可逆形式のビットレート（ステレオ／モノラル）は次のとおりです。

| 形式 | 容量削減 | 標準 | 高音質 |
|---|---:|---:|---:|
| mp3 | 96／56kbps | 160／96kbps | 256／160kbps |
| m4a・aac | 80／48kbps | 128／80kbps | 192／112kbps |
| ogg | 80／48kbps | 128／80kbps | 192／112kbps |
| opus | 48／32kbps | 96／56kbps | 128／80kbps |

opus は、22.05kHz の指定を24kHz、44.1kHz の指定を48kHzにして処理します。WAV・FLACはビットレートではなく、サンプリングレートとビット深度で容量が決まります。

**原音忠実**は wav・flac のみです。元のサンプリングレートとビット深度を使い、flac は最大24bitです。元が非可逆形式の場合は16bitとして扱います。mp3・m4a・aac・ogg・opusは選べず、「この形式は非圧縮ではありません。原音を保つには wav か flac を選んでください。」と表示します。原音忠実を選んだ時点で出力形式が非可逆なら、flacに切り替えて通知します。

**カスタム**を選ぶと詳細設定が表示されます。非可逆形式はビットレートとサンプリングレート、wav・flacはビット深度とサンプリングレートを指定できます。flacでは圧縮レベルも設定できます。他のプリセットでは詳細設定は表示されません。

音声カットの出力名は「元の名前-cut.拡張子」、動画から音声を取り出す場合は「元の名前.拡張子」です。推定出力サイズは選んだ形式・プリセット・チャンネル設定に合わせて表示します。

## 音声カット
音楽編集ソフトのような、1トラックの画面です。

| 操作 | 方法 |
|---|---|
| 切り出す範囲を決める（1） | 上の {icon:select_all} **範囲指定**を押してから、波形を**ドラッグ**した範囲が、切り出す範囲になります |
| 切り出す範囲を決める（2） | 波形の**はじめ**と**おわり**のつまみをドラッグして、範囲を変えます |
| 再生位置を決める | 波形のうえを押す（再生位置の線が動きます） |
| 再生・一時停止 | {icon:play_arrow} / {icon:pause} |
| 選択範囲の最初・最後へ | {icon:skip_previous} / {icon:skip_next} |
| 全体の最初・最後へ | {icon:first_page} / {icon:last_page} |
| 10秒戻る・進む | {icon:replay_10} / {icon:forward_10} |
| 拡大・縮小 | {icon:zoom_in} / {icon:zoom_out} / {icon:fit_screen}（全体表示） |

## 上限とエラー
| 場面 | 上限・エラー |
|---|---|
| 変換できるファイル | 音声・動画は300MBまで、画像は1.2億ピクセルまで（この端末の中で処理する上限） |
| **保存**（システムへ） | 管理設定の「最大アップロードサイズ」まで。超えると「**ファイルが大きすぎます**」と表示し、保存しません |
| **ダウンロード**（端末へ） | 上限はありません |
| メモリが足りない | 「メモリ不足」と表示します。範囲を短くするか、別の端末で試してください |
| WebAssembly が使えない | 変換エンジンが動かないため、音声・動画のツールは使えません。画像リサイズは使えます |
