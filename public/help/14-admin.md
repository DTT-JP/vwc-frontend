# 管理者向け

{icon:admin_panel_settings} 管理は、管理者権限のある人だけに表示されます。

| 項目 | できること |
|---|---|
| 部員 | 追加・無効化・削除、役職と管理者権限の設定、CSV一括登録 |
| 端末 | 全部員の信頼端末の一覧と失効 |
| 制限値 | 容量・アップロード・ログイン・公開などの上限の設定（範囲外は保存できません。保存前に変更点を確認。既定値に戻せます） |
| アプリ | すべてのアプリの状態変更・削除・管理（更新・コード）・閲覧者・孤立アプリの再関連付け・他者のプロジェクトの公開 |
| お知らせ | ホームに出すお知らせの作成・編集・削除 |
| 使用状況・保守 | 使用量ランキング、不要データの回収（GC）、監査ログ |

## 再認証（10分）
管理の**更新の操作**（部員・端末の失効・制限値・アプリ・他者のプロジェクトの公開・GC・お知らせ）は、ログインまたは再認証から**10分以内**にしかできません。

- 管理画面の上に、**再認証の残り時間**が表示されます
- 期限が切れていると、操作を押したときに再認証のダイアログが出ます。認証システムでの再認証を終えると、**押した操作がそのまま続きます**
- 「いま再認証する」で、期限の前に更新もできます

## 制限値
| 項目 | 既定 | 範囲 |
|---|---|---|
| 部員ごとの容量上限 | 500MB | 10〜10000MB |
| 最大アップロードサイズ | 200MB | 1〜2000MB |
| 履歴の追跡上限 | 5MB | 1〜100MB |
| 信頼端末の有効日数 | 90日 | 1〜365日 |
| ログイン用コードの有効秒数 | 300秒 | 60〜900秒 |
| ログイン承認の失敗上限 | 5回 | 3〜10回 |
| アプリの最大サイズ | 200MB | 1〜2000MB |
| 部員ごとのプロジェクト数 | 50個 | 1〜500個 |
| アクセスコードの失敗上限 | 5回 | 3〜10回 |
| 非公開アプリのアクセス有効分 | 60分 | 5〜1440分 |
| 限定公開アプリのアクセス有効時間 | 24時間 | 1〜168時間 |
| 放置アプリの通知までの日数 | 90日 | 7〜730日 |
| 監査ログの保持日数 | 365日 | 30〜3650日 |

## 監査ログ
日時・部員・操作・対象と、操作した端末の**IPアドレス**が残ります。部員・操作・IPで絞り込めます。設定した保持日数より古いものは削除されます。

## 部員を削除するとき
次の順に進みます。

1. 影響するプロジェクト・アプリ・容量を確認します
2. プロジェクトごとに「残す（所有者のいないプロジェクトにする。既定）」「有効な別の部員へ移管」「削除」を選びます。何も選ばずに進むと、プロジェクトは所有者のいない状態で残ります
3. アプリごとに「状態はそのまま（既定）」「非公開」「限定公開」「削除」を選びます。プロジェクトを削除すると、そのアプリは「削除」に固定されます
4. 部員IDを入力して再認証し、削除を実行します

## CSV一括登録
列は `部員ID,名前,メール,役職,管理者権限` の5列です。

```csv
部員ID,名前,メール,役職,管理者権限
U101,新人 一郎,ichiro@example.com,部員,なし
U102,新人 二郎,jiro@example.com,副部長,あり
```

プレビューで、エラーのある行が赤く表示されます。エラーのない行だけを登録できます。
# 管理画面の表示ルール（v3.2）

管理画面の再認証バーは「管理の再認証 あと mm:ss」と表示され、期限切れの場合は「管理の再認証 切れています」と表示されます。表の日付は枠幅に合わせて年・月日を分けて表示し、期間は開始日と終了日を同じ規則で表示します。端末・アプリ・お知らせの行操作はアイコンです。アイコンにマウスを合わせると操作名が表示され、キーボードフォーカスも利用できます。
