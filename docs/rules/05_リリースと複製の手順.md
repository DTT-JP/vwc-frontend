# 05 リリースと複製の手順

規則 ID: `R1`〜。正は `vwc-rules`。原文 §9「リリース手順チェックリスト」を、4つのリポジトリへ広げたもの。

## 1. 規則の複製

| # | ルール |
|---|---|
| R1 | 各リポジトリ（FE・BE・IdP）は、`vwc-rules/rules/` の全ファイルを、自分の `docs/rules/` に複製して持つ。BE は契約の写しを FE へ、IdP 契約の写しを BE へ、さらに複製する（`04` §2） |
| R2 | 複製した各ファイルの先頭に、`04` §10 の**複製ヘッダー**を付ける。本文は変えない |
| R3 | `docs/rules/VERSION` に、複製した `vwc-rules` の版（`VERSION` の値）を書く |
| R4 | 規則を変えたら、`vwc-rules` で版を上げてタグを付け、**各リポジトリが次のリリースまでに**複製を更新する。更新が遅れていてもリリースは止めないが、`CHANGELOG.md` に「規則 x.y.z に未追従」と書く |
| R5 | 原文（`02`）は変えない。変えたいときは、`03` に「読み替え」を足す |

**複製の手順**（`vwc-rules` の版が 1.0.0 のとき）

1. `vwc-rules` の最新タグ（`rules-v1.0.0`）を取得する。
2. `rules/` 配下の全ファイルと `VERSION` を、各リポジトリの `docs/rules/` へコピーする（`VERSION` は `docs/rules/VERSION` へ）。
3. コピーした `rules/` 配下の各ファイルの先頭に、複製ヘッダーを付ける。複製元は `vwc-rules rules-v1.0.0`、コミットは先頭7桁。
4. 各リポジトリでコミットする。メッセージ例: `docs: 規則を rules-v1.0.0 に更新`。

## 2. リリースの手順（共通）

1. 変更内容に応じて、`VERSION` を更新する（`03` §2・§10）。
2. API を足した・変えたなら、契約文書・レジストリ・`CHANGELOG.md` を更新する（BE・IdP。`04` §13）。
3. 契約テスト・回帰テストを通す（各リポジトリ）。
4. `tools/calc-build-hash.*` を実行し、**完全なハッシュ**を `BUILD_REFERENCE` に記録する（FE は `build-manifest.json` も作る）。
5. `CHANGELOG.md` に、その版の変更を書く（`03` §11）。
6. コミットし、タグ（`fe-v…` `be-v…` `idp-v…` `rules-v…`）を付ける。
7. 配備する。順は **IdP → BE → FE**（`01` §4）。
8. 配備後、画面のバージョン表示（FE・BE）と、IdP の画面の版が、`BUILD_REFERENCE` と一致するか確認する。
9. `docs/rules/VERSION` が最新の `vwc-rules` と一致するか確認する（C10）。

## 3. `BUILD_REFERENCE` の書式

```text
# BUILD_REFERENCE（リポジトリ直下。検査対象には含めない）
component: BE
version: 1.1.0
build: 3a8b123
build_full: 3a8b123…（64文字）
date: 2026-12-01
commit: abc1234
```

## 4. 配備前後のチェックリスト（共通）

| 区分 | 確認 |
|---|---|
| 配備前 | 設定ファイル・DB・鍵・利用者のファイルを、配備物に含めていない（`01` §4-6） |
| 配備前 | 所有表（`01` §3）で、パスが重なっていない |
| 配備前 | `.htaccess` を含めて配備する（FE・BE・IdP それぞれ） |
| 配備後 | 画面の版・build が `BUILD_REFERENCE` と一致する |
| 配備後 | `system/` `data/` `config/` が URL から取れない（実機で確認。BE の `docs/21` §8 と同じ手順） |
| 配備後 | ブラウザーを強制再読み込みして、ログイン・管理画面の再認証を見る |

## 5. 戻し方

- 前のタグの配布物を、配備の順の**逆**に置き直す（FE → BE → IdP）。
- IdP の DB のスキーマを変えた版は、戻す前に DB のバックアップを取る。スキーマの変更は、前の版でも動く形（列の追加のみ）にする。
- MAJOR を戻すときは、`03` §6 の手順のとおり、BE と FE を続けて戻す。

## 6. タグと版の対応

| 例 | 意味 |
|---|---|
| `fe-v1.1.0` | FE 1.1.0 |
| `be-v1.1.0` | BE 1.1.0 |
| `idp-v1.0.0` | IdP 1.0.0 |
| `rules-v1.0.0` | 規則 1.0.0 |
