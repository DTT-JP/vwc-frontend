# 06 UI・視覚ルール

規則 ID: `U1`〜。正は `vwc-rules`。各リポジトリの `docs/rules/` はその複製（手順は 05）。

## 1. 目的

画面の見た目・動きに関する共通ルールを定める。FE の画面資材（HTML・CSS・JS）に適用し、BE・IdP が画面資材を持たない前提（B2・B6）と矛盾しない。

## 2. ルール

| # | ルール | 対象 |
|---|---|---|
| U1 | **すべてのアイコンの回転アニメーションを、例外なく等しく禁止する。** アップロード中・読み込み中・処理中など状態を問わず、アイコン要素（例: FE の `.ms` 等、アイコンを表す要素）に対して、回転するアニメーション（`animation`/`@keyframes` による回転、回転を伴うトランジション/動的な回転変化）を入れない。**ただし、特定の角度に回転させた固定表示（`transform: rotate(...)` による静的な向きの指定）は許可する（従来どおり）。** | FE（画面資材）。アイコンを表示する実装全般 |

## 3. 適用時の確認

- CSS/JS/HTML/テンプレートで、アイコン要素に回転アニメーション（`spin` 等の回転 `@keyframes`、回転をアニメーションさせる `transition`/`animation`）が付与されていないこと。状態表示（アップロード中など）も例外としない。
- 既存実装に回転アニメーションクラス付与ロジックが残る場合でも、視覚的に回転アニメーションしないこと（回転アニメーション効果を無効化する）。
- 特定角度の固定回転（静的な向き）は、アニメーションさせなければ従来どおり許容される。
- 見た目の最終確認は、利用者（人間）による確認を要する場合がある。

## 4. 未決事項・要確認

- アイコン以外の要素（進捗バーのインジケータ移動、背景スライド、登場アニメーション等）のモーション可否は、本規則では定めない。必要に応じて別IDで追加する。 [要確認]
- アクセシビリティ上の状態伝達（処理中表示など）を、回転以外の方法で補う必要があるかは、画面ごとに確認する。 [要確認]
