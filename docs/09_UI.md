# 09 UI基本方針（v3.2。画面ごとの詳細は 15。FE リポジトリの文書）
UIの見本は**モック（完成形）**。実装はモックに合わせる。モック操作（`dev/`）は開発用で、実装には含めない。
## 全体
- VS Code 風（アクティビティバー、左エリア、右エリア、タブ、ステータスバー）。画面全体のスクロールは出さない。
- 画面サイズ（PC/タブレット/スマホ。境界600/1024px）は実際の画面幅、入力（マウス/タッチ/ペン）は実際の操作で自動判定。
- 最小文字14px。タップ領域は、タッチ端末で44px以上（PC は標準36px。設定でコンパクト30px/ゆったり44px）。色だけに頼らず、バッジ・状態に文字も付ける。
- アイコンは Material Symbols（使用分だけをサブセットにして同梱）。フォントは Noto Sans JP・JetBrains Mono を同梱。外部CDN・外部通信なし。フレームワークなし。
- 色は色トークンで管理（ダーク/ライト/端末に合わせる、強調色4色）。
## 左バーと左エリア
並び: ホーム｜プロジェクト・ファイル・検索・履歴・共有・公開・ツール・ヘルプ｜（余白）｜管理（管理者のみ）・利用状況・設定・ユーザー。選択中のボタンをもう一度押すと左エリアを隠す。未ログイン中はホームだけ。
## 右エリア（メイン＋サブの2画面）
- PC/タブレット: メイン左・サブ右。スマホ: メイン上・サブ下。サブは既定で閉じ、タブ欄右端のボタンで開閉。プレビューはサブに開く。境界はドラッグで変更（どちらも最低260px）。
- タブ: ドラッグ（タッチは長押し）で並べ替え・メイン⇄サブ移動。青いタブは画面全体で1つ。未保存は●（押すと保存の確認）。
- **タブのメニュー**（右クリック、タッチは長押し）: 閉じる／他を閉じる／右側を閉じる／すべて閉じる（いずれも同じ画面の中）／保存（未保存のとき）／**このタブのファイルのパスをコピー**（ファイルとプレビューのタブ。プロジェクトの根からの相対パス）／サブ（メイン）へ移動／プレビューを開く（HTML・Markdown）。未保存のタブを含む場合は、1つずつ「保存／保存しない／キャンセル」を確認。
- ステータスバー（PC/タブレットのみ）: プロジェクト名（分岐元）、保存状態、行/列、言語、容量。右に「接続状態・プレビュー・現在の処理」。スマホはステータスバーなし。
- スマホ: 下ナビ（戻る/進む｜ホーム/メニュー｜エディター/プレビュー）、補助キー行（タッチ操作のときだけ表示）。
## ファイル一覧
行にポインターを乗せる（選択・開いている行）と、名前変更・ダウンロード（フォルダはZIP）・削除のボタンが出る。ツールバー: フォルダ追加・ファイル追加・アップロード（ファイル/フォルダ。一覧へのドラッグ&ドロップも可）。複数選択（Ctrl/Shift、タッチは長押し）。ドラッグで移動。凡例を一覧の下に常時表示。色と文字は 06。
## エディター
色付き表示の上に透明な入力欄を重ねる自前方式（highlight.js 11.9.0＋追加言語）。行番号、折り返し、タブ幅、Tabで字下げ、Ctrl/Cmd+S で保存。選択色は半透明。閲覧のみは「閲覧のみ：編集できません」の帯と読み取り専用。種別ごとの表示: テキスト（編集）、画像（プレビュー+サイズ）、動画・音声（プレーヤー）、その他（ダウンロードのみ）。
**実装時に検証する項目**: 日本語入力（IME）、大きなファイル、スマホの選択・拡大、アクセシビリティ（16 の「実装時の検証」）。
## キー操作
| キー | 動作 |
|---|---|
| Ctrl/Cmd+S | 保存 |
| Ctrl/Cmd+P | ファイル名検索（候補は上下キー、Enter でそのタブ／新規に開く） |
| Ctrl/Cmd+Shift+P、F1 | コマンド検索。どのブラウザでも両方のキーで開く（ブラウザが Ctrl+Shift+P を奪う環境でも F1 で開ける） |
| Ctrl/Cmd+F | ファイル内検索（右側に出ているものが対象。左エリアは対象外） |
## コマンド検索
ファイル名検索と同じ作りの入力欄＋候補一覧。項目名（と別名）を入れると絞り込まれ、上下キーとEnterで実行、Escで閉じる。スペース区切りは AND。入力が空のときは最近使った項目を先頭に出す。権限のない項目は出さない（管理は管理者のみ。閲覧のみのプロジェクトでは保存系を出さない）。スマホは左メニューの「コマンド」行から開く。
| 分類 | 項目 |
|---|---|
| 画面 | ホーム、プロジェクト、ファイル、検索、履歴、共有、公開、ツール、ヘルプ、利用状況、設定、アカウント |
| 設定 | 外観、文字サイズ、エディター、操作・余白、通知 |
| アカウント | 信頼端末、QR読み取りでログイン、コード入力でログイン、ログアウト |
| 管理（管理者・再認証） | 部員、端末、制限値、アプリ、お知らせ、使用状況・保守 |
| ツール | 画像リサイズ、音声カット、動画から音声 |
| ヘルプ | 各記事のタイトル |
| プロジェクト | 各プロジェクトに切替、新しいプロジェクト、ZIPでダウンロード |
| アプリ | 新しく公開、各アプリを管理、各アプリを開く |
| ファイル・編集 | 保存、すべて保存、プレビュー、ファイル内検索、全体検索、新規ファイル/フォルダ、アップロード、このファイルのパスをコピー、コミット |
| 表示 | ダーク/ライトの切替、サブ画面の開閉、左エリアの表示/非表示 |
## 保存と警告
保存は手動。未保存（青）のタブ/ファイルがあるまま、タブを閉じる・プロジェクトを切り替える・ログアウトする場合は確認ダイアログ（「保存されていない変更があります。保存しますか？」保存/保存しない/キャンセル。Esc・外側では閉じない）。ブラウザ離脱は `beforeunload` の標準警告。
## プレビューと言語
HTMLは sandbox iframe（サーバー配信。05）。Markdown は端末内で描画（チェックボックスを押すと元の `.md` が未保存で書き換わる。Mermaid対応）。言語は拡張子で色付け（HTML/CSS/JS/JSON/Markdown ほか多数）。
## ホーム・設定・ヘルプ・お知らせ
15 を参照。設定は端末内（localStorage）に保存し、端末間では同期しない。

## 日付の表示規則（全画面共通）
日付は `YYYY-MM-DD`（年4桁-月-日）で表示し、**日付の途中では折り返さない**。置かれた枠の幅に応じて、入る中で最も横に広い形を選ぶ（画面幅ではなく、その枠の幅で決める）。
**期間（開始〜終了）**
| 幅 | 表示 |
|---|---|
| 狭い | 3行: `1234-56-78` / `～` / `1234-56-78` |
| 中 | 2行: `　1234-56-78`（先頭に全角スペース）/ `～1234-56-78` |
| 広い | 1行: `1234-56-78～1234-56-78` |
**日付1つ（更新日・作成日・最終利用・有効期限など）**
| 幅 | 表示 |
|---|---|
| 広い | 1行: `1234-56-78` |
| 中 | 2行: `1234` / `56-78` |
| 狭い | 3行: `1234` / `56` / `78` |
- 時刻を伴う表示（監査ログなど）は、日付に上の規則を適用し、時刻は日付の下に置く。
- 入力欄（`input[type=date]`）には適用しない。
## 管理画面の表の共通規則
- 行の操作ボタンはすべて**アイコンのみ**（ラベルなし）。1行の中で横に並べ、折り返さない。同じ表の中で、アイコンの位置・縦位置を行ごとに揃える（使えない操作は、場所だけ空けて詰めない）。各ボタンに `aria-label` と `title`（説明）を付ける。
- アプリの「放置」「孤立」などのバッジは、**公開名の下に、どんなときでも**表示する。

## フロントエンドの配布とライセンス表示
- FE は `public/` をそのまま `editor/` に置けば動く（ビルド工程なし）。設定は `config.js`（`apiBase`。`requiredApi` は FE 2.0 で廃止）だけ。API の MAJOR 版が合わないときは、全画面で「サーバーとエディターの版が合いません」を表示。
- **ライセンスの表示**: ヘルプに「ライセンス」記事、設定に「ライセンス」の行、ログアウト時のホーム（左・右）の「ライセンス」。設定とホームの入口は、右エリアのタブとして `license/*.md` を Markdown 描画で表示する（バックエンドに依存しない）。内容は、このソフトウェアが GPL-3.0-or-later であること、同梱の第三者部品の一覧、ffmpeg コアのソースの入手先、ソースリポジトリのURL。
- FE の入口は URL契約（04）のパラメータで開き方が変わる: `?approve=` は承認画面（S02）、`?gate=` はアプリの入口（S19）、`?auth=` はログイン結果の処理。
- Mermaid の描画用ページ `mermaid-frame.html` も FE の静的ファイル。
