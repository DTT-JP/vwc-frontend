# 08 ツール（v3）
**ルール: 画像・音声・動画の処理はすべてローカル（端末内のブラウザ）で行う。サーバー側の処理は使わない。処理用のライブラリは自サーバーから配信し、外部サービスへ送信しない。サーバーへ送るのは、処理後に「保存」を選んだファイルのみ。**
## 共通
- ツールは「登録」（ID・名前・アイコン・説明・受け入れる入力・画面・実行・出力）だけで、左のツール一覧、入力選択、出力、進捗、中止、エラー、Media を使える（モックの `Tools.register`。手順は `docs/ツール追加ガイド.md`）。
- 入力元: 端末のファイル（ドロップ可）／システム（プロジェクト）のファイル。出力: 「保存」（開いているプロジェクト／選択中フォルダへアップロード。`max_upload_mb` 超は「ファイルが大きすぎます」で保存しない）／「ダウンロード」（上限なし）。
- ツールの入力上限は各ツールのコードで持つ: 音声・動画 **300MB**、画像 **1.2億画素**。足りないメモリは「メモリ不足」エラー。
- **Media サービス（ffmpeg.wasm）**: アプリ全体で1つ。初回の呼び出しで自動で読み込み、以降は再利用。同時実行は1件で、待ち数を表示。中止・失敗の理由（WebAssemblyなし・読み込み失敗・メモリ不足・形式非対応・音声なし）を共通表示。ステータスバーの「現在の処理」と連動。1件ごとに新しいインスタンスで実行（使い回すと opus で止まることがあるため）。opus は圧縮レベル3に固定。
- 配置は FE の `public/vendor/ffmpeg/`。`@ffmpeg/ffmpeg` 0.12.15（MIT）＋ `@ffmpeg/core` 0.12.10（シングルスレッド、約31MB。FFmpeg 5.1.4 を `--enable-gpl` でビルド。x264・x265・libvpx・LAME・Vorbis・Opus などを含む）。
- **ライセンスと境界（19）**: コアは **GPL-2.0-or-later**。FE 全体を **GPL-3.0-or-later** で公開し、BE にはこのコアも FE のコードも入れない。`Media`（`js/media.js`）だけがコアに触り、各ツールは `Media` の関数を呼ぶだけにする。FE の配布物には、`LICENSE`・`NOTICE.md`・`vendor/ffmpeg/SOURCE.md`・`licenses.html`（アプリ内「ライセンス」）を含め、ソースの入手先を wasm のすぐ近くに明示する。
- Worker が必要で `file://` では動かない。WebAssembly が使えない環境には、ツールの先頭に案内を出す。
- 確認済みの形式（実ブラウザで全入力×全出力を変換して検証。`vendor/ffmpeg/verified.json`）: 入力（音声）aac・ac3・aiff・amr・au・caf・flac・m4a・mka・mp2・mp3・ogg・opus・wav・wma、入力（動画）3gp・avi・flv・mkv・mov・mp4・mpg・ogv・webm・wmv。出力 wav・mp3・flac・m4a・ogg・opus・aac。確認済み以外でも、ffmpeg が読めれば入力できる。
## 画像リサイズ
入力: ブラウザが表示できる画像（png・jpeg・webp・gif・bmp・ico・svg など）。設定: 幅・高さ（縦横比固定）、出力形式（jpeg・png・webp・bmp・ico［256px以内］）、品質（jpeg/webp）。プレビューと出力サイズを表示。出力名 `元名-幅x高さ.拡張子`。
## 音声カット
- 1トラックの波形エディター: 波形、はじめ/おわりのつまみ、数値入力、範囲指定、再生位置、拡大縮小、選択範囲だけ再生、移動ボタン（選択範囲の最初/最後、全体の最初/最後、10秒戻る/進む）。
- 出力形式: **wav / mp3 / m4a / aac / ogg / opus / flac**（実際に使える形式だけを表示）。出力名 `元名-cut.拡張子`（重複は ` (1)`）。
- 画面: 「出力形式」「品質」「ステレオ/モノラル」を横に並べる。**詳細設定は「カスタム」のときだけ表示**（それ以外は隠す）。推定出力サイズ、進捗、中止を表示。
### 品質プリセット（数値は初期案。実装時の聴き比べで調整してよい）
プリセット: 容量削減 / 標準 / 高音質 / 原音忠実 / カスタム。
- **容量削減・標準・高音質**は、どの形式でも使える。**サンプリングレートとビット深度はプリセットごとに形式によらず固定**し、ビットレートは形式の圧縮効率に合わせて、同じ程度の音質になる値にする。
| プリセット | サンプリングレート | ビット深度（wav/flac） | mp3 | m4a・aac | ogg(Vorbis) | opus | flac の圧縮 |
|---|---|---|---|---|---|---|---|
| 容量削減 | 22.05kHz | 16bit | 96k | 80k | 80k | 48k | レベル8 |
| 標準 | 44.1kHz | 16bit | 160k | 128k | 128k | 96k | レベル5 |
| 高音質 | 48kHz | 24bit | 256k | 192k | 192k | 128k | レベル8 |
（ビットレートはステレオの値。opus はサンプリングレートに 8/12/16/24/48kHz しか使えないため、22.05kHz→24kHz、44.1kHz→48kHz に最も近い値で処理する。）
- **ステレオ/モノラル**は、どのプリセットでも出力形式の横で切り替えられる（プリセットで固定しない）。モノラルにすると、ビットレートはステレオの約6割に下げる: mp3 56/96/160k、m4a・aac・ogg 48/80/112k、opus 32/56/80k。
- **原音忠実**: **可逆圧縮または無圧縮の形式（wav・flac）でのみ選べる**。サンプリングレートとビット深度は元の音声と同じ（flac は24bitまで。元が可逆でない形式のときは16bitとみなす）。非可逆の形式を選ぶと、その形式は選べず、理由として「この形式は非圧縮ではありません。原音を保つには wav か flac を選んでください。」を表示する。原音忠実を選んだとき出力形式が非可逆なら、flac に切り替えて知らせる。
- **カスタム**: 詳細設定を表示する。非可逆はビットレート・サンプリングレート（形式が対応する値）、可逆はビット深度・サンプリングレート（flac は圧縮レベルも）。ステレオ/モノラルは詳細設定の外のボタンのまま。
- 初期値: mp3 / 標準 / ステレオ。
## 動画から音声を取り出す
入力: ffmpeg が読める動画（音声ファイルも可）。出力形式・プリセット・ステレオ/モノラルは音声カットと同じ。出力名 `元名.拡張子`。
## 共通のエラー
形式非対応、サイズ超過、メモリ不足、WebAssembly非対応、変換エンジンの読み込み失敗、中止。保存時は「ファイルが大きすぎます」。
